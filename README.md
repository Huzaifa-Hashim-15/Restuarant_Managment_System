# 🍽️ Restaurant Management & Food Ordering System

A modern web-based Restaurant Management and Food Ordering System developed using PHP, MySQL, Bootstrap, JavaScript, HTML, and CSS. This project helps restaurants manage menu items, employees, customer orders, reservations, and admin operations through an interactive dashboard.

## 🚀 Features

* 🔐 Admin Dashboard
* 🍔 Dynamic Food Menu System
* 🛒 Online Food Ordering
* 👨‍🍳 Employee Management
* 📅 Table Reservation System
* 📦 Order Management
* 💳 Billing & Payment Handling
* 📊 Restaurant Statistics Dashboard
* 📱 Responsive Bootstrap Design
* 🔍 Search & Filter Functionality
* ⚡ Real-Time CRUD Operations using APIs

## 🛠️ Technologies Used

* PHP
* MySQL
* JavaScript
* Bootstrap 5
* HTML5
* CSS3

## 📂 Project Modules

### Admin Panel

* Manage employees
* Manage menu items
* View customer orders
* Update order status
* Manage reservations

### Menu System

* Add/Edit/Delete food items
* Dynamic food display
* Smart image handling system

### Reservation System

* Book tables online
* Store customer reservation data

### Employee Management

* Add new employees
* Update employee details
* Manage salaries and roles

## ⚙️ Installation

1. Download or clone the repository

2. Move project folder to:
   xampp/htdocs/

3. Import the SQL database file into phpMyAdmin

4. Start Apache and MySQL from XAMPP

5. Open browser and run:
   [http://localhost/webprojectfinal](http://localhost/webprojectfinal)
